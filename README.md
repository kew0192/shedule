📚 Школьная система управления расписанием
Современный веб-инструмент для создания, редактирования и экспорта школьных расписаний с ролевой моделью доступа.

Система разработана для администраторов школ, завучей и учителей, которым нужен прозрачный и контролируемый процесс ведения расписания. Вместо хаоса из Excel-файлов и бумажных таблиц — единая база, где каждый видит только то, что ему положено, а ошибки при добавлении уроков блокируются на уровне логики.

🚀 Быстрый старт
Обратитесь к администратору системы для получения индивидуального кода авторизации.

Перейдите на страницу входа и введите полученный код.

В зависимости от вашей роли вам будут доступны определённые функции.

⚠️ Внимание! Вход без кода невозможен. Код выдаётся только ответственным лицом и является персональным.

👥 Управление пользователями
«Пользователи»
Открывает таблицу со всеми зарегистрированными в системе пользователями. Для каждого отображаются:

Имя пользователя

Роль (админ или учитель)

Уникальный код авторизации

Используйте эту вкладку для контроля доступа и при необходимости перевыпуска кодов.

📤 Экспорт расписания
«Экспорт»
Скачивает расписание выбранного класса в формате .xlsx.
В системе всегда выбран какой-то класс — именно по нему и происходит экспорт. Чтобы изменить класс, просто выберите другой в выпадающем списке, и экспорт будет выполнен уже для него.

«Экспорт всех»
Выгружает расписания всех классов в одном Excel-файле.
Файл представляет собой единую сводную таблицу, где отображаются все классы, все дни недели и все уроки. Это позволяет увидеть полную картину загрузки школы: какие классы, в какое время и с какими учителями занимаются. Идеально для завуча или директора, чтобы оценить равномерность нагрузки и выявить возможные пересечения.

«Моё расписание»
Доступно для учителей и классных руководителей.
Скачивает персональное недельное расписание пользователя, под которым выполнен вход.
Больше не нужно искать себя в общих таблицах — система сделает это автоматически.

➕ Управление классами и уроками
«Добавить класс»
Создаёт новый класс в системе.
Формат ввода: строго 10-А, 7-Б, 11-В и т.д.
После создания класс появляется в списке и автоматически становится выбранным.

«Добавить Уроки»
Самый строгий и ответственный инструмент системы. При добавлении уроков действуют жёсткие проверки:

Правило	Описание
✅ Учитель не пересекается	Один преподаватель не может быть занят в одно и то же время в разных классах
✅ Уроки не дублируются	У класса не может быть двух одинаковых предметов в одно время
✅ Не более 3 технических предметов в день	Технические предметы (математика, физика, информатика, химия и т.п.) — не больше трёх в один день
🔁 Особенность добавления
Если один учитель ведёт несколько предметов (например, Адильбуриев Артур — математику и геометрию), нужно создать две отдельные записи:

Адильбуриев Артур — Геометрия

Адильбуриев Артур — Математика

📝 Важно при вводе! При добавлении урока всегда вводите сначала имя, потом фамилию учителя (например: Артур Адильбуриев). Это обязательный формат, чтобы система корректно идентифицировала преподавателя.

🛑 Важно! Если вы ошиблись при добавлении урока (неправильный учитель, время или предмет) — исправить это невозможно. Единственный способ — удалить класс и создать его заново. Редактирование отдельных уроков не предусмотрено намеренно, чтобы избежать цепных ошибок.

👨‍🏫 Учителя: два типа учётных записей
Система различает два типа учительских аккаунтов, и их нельзя путать.

Тип	«Учитель на Просмотр»	«Учитель на Расписание»
Что может	Вход по коду, просмотр и экспорт расписаний, скачивание личного расписания	Всё, что и «на просмотр», плюс добавление в уроки
Что НЕ может	Редактировать или добавлять уроки	—
Роль в системе	Учитель	Учитель
Для чего	Рядовые учителя, которым нужно только видеть расписание	Преподаватели, которые фигурируют в самом расписании
⚠️ Критично! Если вы создали учителя как «Учитель на Просмотр» и попытаетесь добавить его в расписание — система выдаст ошибку. Для работы с уроками нужно выбирать только «Учитель на Расписание». Это два разных типа учёток, и они не взаимозаменяемы.

🗑️ Удаление и выход
«Удалить класс»
Полностью удаляет класс вместе со всем расписанием, привязками учителей и уроками.

🛑 Действие необратимо! Удалённый класс невозможно восстановить — только создать заново с нуля.

«Выйти»
Завершает сессию пользователя и возвращает на экран входа. Рекомендуется использовать при работе с общего компьютера.
